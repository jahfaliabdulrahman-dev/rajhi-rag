# مُدقّق كشوف الراجحي · rajhi-rag

من المسح الضوئي إلى الجواب الموثّق: يقرأ التطبيق **كشوف حساب مصرف الراجحي الممسوحة ضوئياً** (PDF بلا طبقة نصية)، يتحقق من كل رقم، ثم يجيب عن أسئلتك بالعربية — مع دليل تتبّعي لكل جواب.

> **النطاق بصدق:** هذا إصدار تجريبي مبني ومقيس على **عيّنة من 10 صفحات (≈1.6%)** من كشف من 629 صفحة. لا ادعاء تغطية كاملة قبل اجتياز بوابات التوسع المتدرّج (`tools/scale_slice.py`).

## لماذا يثق المرء بالأرقام؟

ثلاث طبقات، وكل رقم قابل للطعن:

1. **قراءة** — نسخ حرفي للأرقام كما طُبعت (VLM) ثم تطبيع حتمي (فاصلة عشرية قديمة/نقطة حديثة/صفر منقّط).
2. **تحقق** — *السلسلة الرصيدية هي الحَكَم*: كل حركة تُشتق من فرق الرصيدين، والاتجاه يُستنتج — لا يُخمَّن. و**أوراكل الفوتر**: الإجماليات المطبوعة في أسفل كل صفحة (مدين/دائن/الرصيد التراكمي) تُطابَق آلياً مع مجموع السلسلة — الحارس الخارجي ضد انزياح موحّد ×100 يمرّ «نظيف السلسلة».
3. **فهم** — استرجاع عربي (FAISS + e5) + **أدوات حتمية**: النموذج يستدعي الأدوات ويصوغ الجواب، **ولا يحسب أبداً**. لوحة «الصفوف التي بُني عليها الجواب» تعرض ما لمسته الأدوات فعلاً.

## الخصوصية

- **لا بيانات حقيقية في هذا المستودع.** الـfixture العام **اصطناعي** (`data/sample/statement_sample.pdf`) وكل العينات الحقيقية تعيش خارج git تماماً.
- القراءة تعمل عبر خدمة سحابية (VLM): لا ترفع كشفاً حقيقياً إلا إذا قبلت بمعالجته سحابياً، ولا ترفعه إلى سطح عام.
- حزمة النشر الآمن: `tools/publish_guard.py` (سكانر pre-push + حاجز CI) يرفض المسارات الشخصية وأرقام الحسابات والأسماء العائلية أيّاً كان موقعها.

## تشغيل محلي

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# مفتاح OpenRouter للقراءة البصرية
echo 'OPENROUTER_API_KEY=...' > .env

python app.py            # واجهة Gradio عربية على :7860
```

الخدمات الدائمة (launchd):

```bash
tools/install_services.sh
```

## بوابة الجودة قبل أي «تم»

```bash
python tools/qa_gate.py --full    # اختبارات + صحة الخدمة + تشغيل حقيقي بقيم مقفلة عينياً
python tools/publish_guard.py --tree --history   # قبل أي push
```

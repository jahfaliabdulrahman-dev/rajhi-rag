**أي FAIL = لا تسليم.** أصلح وأعد التشغيل.

## ٢. الفحص اليدوي (خمس دقائق)

1. **نفس السطح الذي سيستخدمه المالك** — افتح `http://127.0.0.1:7860` بمتصفح حقيقي وامشِ المسار كاملاً (رفع → زر → نتيجة). فحص API وحده لا يكفي.
2. **القيم مقابل الأصل** — افتح رندر الصفحة عينياً وقارن أول ٣ صفوف بمخرجات التطبيق. السلسلة «النظيفة» لا تكشف انزياحاً موحّداً (×100) — المقارنة العينية إلزامية.
3. **سطح واحد فقط** — لا قوالب/عروض توضيحية موازية أمام المالك؛ أي سطح ثانٍ يجب أن يحوّل أو يُغلق.
4. **الخصوصية** — كشوف حقيقية لا تغادر الجهاز ولا تدخل أي prompt؛ الـfixture العام اصطناعي.
5. **الخدمتان الدائمتان** — `launchctl list | grep rajhi` (app + redirect). بعد أي تعديل كود: `launchctl kickstart -k gui/$(id -u)/com.jahfali.rajhi-rag`.
6. **التوثيق** — commit + سطر في `references/rajhi-rag-state.md`: ما فُحص وما لم يُفحص، وبأي دليل.

# مخططات المشروع — عربية بالكامل (RTL)

مخرجان بصريان جاهزان للتسليم. كل ملف **صفحة HTML واحدة مكتفية بذاتها**: تُفتح في
المتصفّح مباشرة، بلا إنترنت، بلا سيرفر، وبلا أي طلب خارجي.

| الملف | ماذا يوضّح |
| --- | --- |
| `rajhi-rag-architecture.ar.html` | **المكوّنات والحدود** — «من المسح الضوئي إلى جوابٍ موثّق»: ما يعمل على الجهاز، وأين يخرج شيءٌ إلى الشبكة: **خروجُ البيانات الوحيد** إلى مزوّد النموذج، ونموذجُ التضمين يُنزَّل من Hugging Face (ملفّاتُ نموذجٍ لا بياناتُ كشف) |
| `rajhi-read-workflow.ar.html` | **المسارات والخطوات** — «من رفع الورقة إلى تصدير Excel»: أنبوبُ القراءة والتحقّق، مع مسار الاستدراك عند سلسلة مكسورة |

العربية هي لغة الصفحة كلها، والاتجاه من اليمين إلى اليسار في **الكروم والمشهد معًا**:
العنوان، شريط الأدوات، المفتاح، ترويسات المسارات، وتدفّق المخطّط نفسه يبدأ من اليمين.

**وما يصفه المخطّطان هو `main` عند التزام التثبيت أدناه، لا خطّةً.** فحدُّ نداءات الوكيل ومهلتُه (جولة R108/R109)
لا يظهر فيهما حتى تهبط تلك الجولة؛ ويُضاف حينها إلى `source/` بسطرٍ ويُعاد التوليد.

## الأدلة

- بوابات `finalize` الأربع على كل ملف: `validate` · `deliver` · `check` · `browser-check` → **`pass`**.
- `visual-check` (خمس فحوص: containment · readability · viewerChrome · themeStates · captures) → **`pass`** على الملفّين.
- المراجع (ملفات المشروع التي يستشهد بها المخطّط) **مثبّتة على التزام المستودع `6350289`**:
  **28 مرجعًا** في المخطّط المعماري و**14** في سير العمل، وحالة `verified: true`.
- **بصمتا الملفّين المودَعين** (sha256):

  | الملف | sha256 |
  | --- | --- |
  | `rajhi-rag-architecture.ar.html` | `ddc8ff210fac497348b7d484e27a21d00bce8b742cac1c08b38fb76418b16709` |
  | `rajhi-read-workflow.ar.html` | `770aa46456cb01b50b00605372a2cb2b695357251f5d036ad0a5f4b75c3f0ffd` |

- **الإيصالاتُ نفسُها محلّيّة لا تُتتبَّع** (`finalize` · `browser-check` · `visual-check` · `delivery`، واللقطات PNG):
  - Archify يكتب فيها **مساراتٍ مطلقة** تحمل اسمَ مستخدم الجهاز، و`tools/publish_guard.py` يحجبها (`home_path`).
  - والـCI يفحص **التاريخ كلَّه**.
  - **فالمودَعُ خلاصتُها أعلاه**، والإيصالاتُ تُعاد بالأمرين أدناه في دقائق.

## إعادة التوليد

المدخلان المؤلَّفان في `source/` (JSON). **من مجلّدٍ خارج المستودع** (فالأداة لا تُنشئ مجلّدَ تشغيلٍ داخله)،
وبمساراتٍ مطلقة:

```bash
node ~/.hermes/skills/creative/archify/bin/archify.mjs finalize architecture \
  <repo>/docs/diagrams/source/rajhi-rag-architecture.candidate.json \
  <repo>/docs/diagrams/rajhi-rag-architecture.ar.html --quality showcase --repo-root <repo>

node ~/.hermes/skills/creative/archify/bin/archify.mjs finalize workflow \
  <repo>/docs/diagrams/source/rajhi-read-workflow.candidate.json \
  <repo>/docs/diagrams/rajhi-read-workflow.ar.html --quality showcase --repo-root <repo>

node ~/.hermes/skills/creative/archify/bin/archify.mjs visual-check <repo>/docs/diagrams/<name>.ar.html \
  --out-dir <repo>/docs/diagrams/.evidence --summary --require-provenance
```

تعديل المدخل ثم إعادة `finalize` يعيد توليد المخطّط، **ويُبطل شهادة التحقّق القديمة** عمدًا: شهادة على بايتات
قديمة لا تُقبل كدليل على بايتات جديدة.

- **والإيصالُ القديمُ يُزال قبل إعادة التوليد.** `browser-check` لا يكتب فوق إيصالٍ لا يملكه، وهذا مقصودٌ في الأداة.

## الأداة

Archify `3.1.0` (رخصة MIT) مع تخصيص محلي للعربية واتجاه RTL موثَّق في مهارة `archify`.

- **المرجعُ والفرق:** `references/local-rtl-and-arabic.md`، والفرقُ كاملًا في `references/patches/`.
- **وأُضيف للتخصيص في 2026-10-14 ثلاثةُ أمور،** وكلُّها تحت `dir="rtl"` وحده، فمخرَجُ اليسار-لليمين يبقى بايتاتِ الأصل:
  1. **خطٌّ عربيٌّ نسبيٌّ بعد JetBrains Mono مباشرة.** فالعربيّةُ كانت تسقط إلى خطٍّ أحاديّ العرض، فيأخذ كلُّ حرفٍ خانةً ثابتةً متّصلًا ممطوطًا.
  2. **صفرُ تباعدِ أحرف.** فالتباعدُ يفكّ الحروفَ العربيّةَ المتّصلة.
  3. **تقريبُ ضجيج الأعداد العشريّة** في المشهد إلى ثلاث خانات (عددٌ مثل ٢٠٢٫٤ كان يُكتب بخمس عشرة خانةً عشريّة). كان يتضخّم به الملف، ويقرؤه حارسُ
     النشر أرقامَ حسابات (`long_digits`).
- **ولا اعتماديات وقت تشغيل، ولا توليد بنموذج لغوي:** الهندسةُ مؤلَّفةٌ في ملفّات `source/`، والأداةُ تُصيّرها وتقيسها.

# معايرة ملف كشف جديد (Onboarding) — ما يعمل مباشرةً وما يلزم قياسه

> سؤال المالك (2026-09-16): «هل المشروع متوافق مع هذا الملف فقط أم أن التصليحات ستعمل مع كشف راجحي آخر؟»
> الجواب الهندسي: **البنية عامة، والمقاسات خاصة بكل مسح.** التصليحات نفسها (السلاسل، الأوراكل، الاستدراك، التحكيم) لا تعرف شيئاً عن هذا الملف تحديداً — لكن كل رقم «قفلناه» (قيم العينة، إحداثيات القصاصات) يخصّ هذه المسحة ويجب معايرته من جديد.

## ١) يعمل مباشرةً على أي كشف راجحي (عام بالتصميم)

| المكوّن | لماذا عام |
|---|---|
| `vlm_reader` + FRONTIER | تعليمات نسخ حرفي لأرقام عربية-هندية — لا تفترض تخطيطاً |
| `chain_derive` (السلسلة + carry/txn/anchor) | رياضيات الرصيد المتتالي — لا تعرف الملف |
| `footer_oracle` (الأوراكل + الدلتا + الحالات ok/mismatch/gap/unchecked/absent) | منطق مقارنة؛ وإن غاب الإطار يعود `absent` بأمان |
| آليات الإصلاح: `recover_anchor` · `try_page_reread` · القراءة المجزّأة · إسقاط الصف الشبح | تُشترط بالمطابقة لا بالتخمين — تعمل على أي ملف |
| `ordering` (تواريخ + رقم الصفحة + فجوات/تكرار/رجوع) | إشارات مستقلة عن الملف |
| `bank_check` (حارس الراجحي) · `era` (الصيغ) · `job_lock` · حمايات الميزانية والإخفاقات | حراس تشغيل |
| `publish_guard` + العدّاد (ledger) + بوابة QA | سلامة وتسعير |

## ٢) يعمل **بشرط قياس واحد** (يُتحقق منه في أول 10–30 صفحة)

| المكوّن | ما يُقاس | إن فشل؟ |
|---|---|---|
| **دلالات الإطار** (تراكمي من بداية الكشف — مُثبت لهذا الملف) | ص1 تطابق الافتراضين، ص2+ يحسم | لو كان التخطيط مختلفاً: الأوراكل يعرض `mismatch` بفروق مقيسة — **لا تُعمَّم الدلالة قبل التحقق** |
| **موضع الإطار** (قصاصة أسفل 25%) | أن الأرقام الثلاثة تُقرأ | إطار غير مقروء ⇒ `absent` (لا ضرر — نعرف أنه غير متحقق) |
| **موضع رقم الصفحة** (سطر التواريخ، يسار الوسط) | القاعدة 5 في FRONTIER تُعيد الرقم | غير مقروء ⇒ `null`؛ فحص التعاقب يكشف القفزات |
| **الصيغة/الحقبة** | الفواصل العشرية والآلاف (عتيقة/حديثة/مختلطة) | تقرير إعلامي فقط (لا يمنع) |

## ٣) خاص بهذه المسحة (يُعاد توليده لكل ملف — إلزامي)

1. **عيّنة مرجعية**: 10 صفحات + **قيمها المقفلة** (ص1: 0.00→+300.00→200.00→100.00 · ص2: +50.00 …) ← هذه تُكتب في `tools/qa_gate.py` من جديد.
2. **الفيّكسترة العامة**: العينة الاصطناعية (لا تلمس بيانات حقيقية).
3. **خط الأساس**: نسب النظافة/الفوتر/الشذوذ لهذا الملف (629 ورقة: 99.6% · 621 موثّق · فجوتا مسح…) — لا تُقارن ملفاً بملف.
4. **سجل الشكوك** يبدأ نظيفاً.

## إجراء المعايرة (نصف يوم، بتكلفة ~$1–2)

```bash
# 1) الحارس: هل هو كشف الراجحي؟
python3 -c "from statement_qa.bank_check import probe_bank; ..."   # أو عبر التطبيق مباشرة

# 2) عيّنة 10 صفحات + قياس أساسي
.venv/bin/python tools/scale_slice.py --first 1 --count 10 --out data/local_sample/<new>_10p

# 3) قارن: نظافة السلسلة؟ فوتر ok؟ أرقام صفحات متسلسلة؟ أي فجوة؟
#    - إن ظهرت فوتر ok بأغلبية الصفحات ⇒ الدلالات والقواعد تنطبق
#    - إن كان كل شيء mismatch ⇒ تحقق من دلالات الإطار (تراكمي؟) قبل المتابعة

# 4) اقفل القيم الذهبية الجديدة في tools/qa_gate.py (نفس البوابة، عيّنة جديدة)

# 5) السلّم: 30–50 → 150 → الكامل، بنفس حواجز التوقف
.venv/bin/python tools/scale_slice.py --first 1 --count 150 --out data/local_sample/<new>_150p --max-cost 3
```

**قاعدة الحكم:** لا يُعتبر ملف جديد «مدعوماً» حتى تمرّ عليه: (أ) العينة المقفلة في البوابة 5/5، (ب) سلايس 150 بأمان، (ج) فجوات/تكرار الترقيم مسماة إن وُجدت.

## ١) الدَّينُ المُعلَن انتهى — صفرُ ظهورٍ في صفرِ ملفّ

القاعدةُ التي حكمت: **«لا يُعفى موضع، تُغيَّر القيمة»** (قرارُ المالك، وقد نُفِّذ حرفيًّا).

| ما قِسته | الأمر | الناتجُ الحقيقيّ |
|---|---|---|
| صيغُ المبالغ الحقيقيّة في الشجرة | `.venv/bin/python tools/amount_guard.py --json` | **٢٤ صيغةً** لـ**١٣ قيمةً** مميّزة في **١٠ ملفّات** |
| بعد التعويض بقيمٍ صناعيّةٍ محجوزة | `--ratchet` | **0 ظهوراً في 0 ملفّاً** |
| الاختبارات | `.venv/bin/python -m pytest tests/ -q` | **404 تمرّ · 1 تُخطّي بإعلان · صفرُ سقوط · صفرُ xfail** |
| خطُّ الأساس | `--baseline-write` ثم `--ratchet` | `0 ظهوراً في 0 ملفّاً` ⇒ **أيُّ ظهورٍ جديدٍ يسقط قطعاً** |
| الفحصُ الشامل | `python3 tools/amount_guard.py` | PASS — لا مبلغَ حقيقيّ في أيّ ملفٍّ مُتتبَّعٍ أو غيرِ مُهمَل |
| برهانُ السقاطة | `tools/ratchet_proof.py` | PASS — 4/4 على نسخةٍ مؤقّتة (وفيها **ضابطٌ موجب**) |

**كيف عُوِّض (لا «أُرضيت الاختبارات»):**
- التعويضُ **رتيبٌ** يحفظ كلَّ مقارنةٍ (لا يُبدّل ترتيباً)، ويحفظ **الشكل**: فاصلةُ الآلاف · الأرقامُ
  العربيّة · الإشارة · عددُ الخانات العشريّة.
- **العلاقاتُ الحسابيّة أُعيد اشتقاقُها** لا تُرضّيت: الفيكستراتُ التي تحرس «الرصيد = السابق ± الحركة»
  أُعيد حسابُ أرصدتها من مبالغها الجديدة (`9011.00 − 120.50 = 8890.50` · `8890.50 + 9002.55 = 17893.05` ·
  والمكسورةُ بفرق `0.10` كما كانت)، و`identity` أُعيد حسابُها (`4766.52`)، واختباراتُ الأدوات صارت
  تسأل بالمبلغ الجديد (`9001`) لا القديم.
- كلُّ قيمةٍ بديلةٍ **مُتحقَّقٌ أنّها خارج المنع** قبل كتابتها (فلا نُنشئ دَيناً جديداً بالعلاج).

## ٢) تاريخُ git مُطهَّر — لا مفتاحَ ولا بصمةً ولا صيغةَ مبلغ

| الخطوة | الأمر | الناتجُ الحقيقيّ |
|---|---|---|
| نسخةٌ احتياطيّةٌ مرآتيّة | `git clone --mirror` | `~/Hermes_Archive/rajhi-rag-mirror-20260923-014518.git` · **٢٦٦ التزاماً · 4.4M** |
| تعدادُ التسريب في كلّ التاريخ | مسحُ **٢٢٩٦ blobاً** بالبصمات المنشورة | **١٢٧ صيغةً** لمبالغَ حقيقيّة |
| التطهير | `git filter-repo --invert-paths --replace-text --replace-message` | المسارات: `data/.amount-guard-key` · `docs/security/amount-denylist.json` ⇒ **أُزيلت** |
| المساراتُ الحسّاسة في التاريخ | `git log --all --name-only \| grep -c` | **0** |
| بصماتُ blobs المفتاح (أربعة) | `git rev-list --all --objects \| grep -c <sha>` | **0 · 0 · 0 · 0** |
| مسحُ التاريخ كلِّه بعد التطهير | `python3 tools/amount_guard.py --history-audit` | PASS — **١٠٦٠ blobاً · ولا صيغةَ مبلغٍ حقيقيّ واحدة** |
| الالتزامات | `git rev-list --all --count` | **٢٦٦** (لم يُفقَد التزام) |
| الاختباراتُ على التاريخ المُطهَّر | `pytest -q` | 404 تمرّ · 1 تُخطّي |
| الدفع | `git push --force` (15 فرعاً) | `main: e2c9344 → ec087f0` · وCI أخضر |
| **التحقّق من الريموت نفسِه** | `git clone --mirror` ثم `--history-audit` على المستنسخ | **PASS · وصفرُ مسارٍ حسّاس** |

**الحمايةُ لم تُختَرق:** دفعُ `main` كان مردوداً بحماية الفرع ⇒ فُتحت **مؤقّتاً** (`allow_force_pushes`)
ثم **أُعيدت مطابقةً للأصل بالأمر**: `enforce_admins=true` · `allow_force_pushes=false` ·
`allow_deletions=false` · وفحصُ `guard` (strict) ✓ — والمقارنةُ محفوظةٌ في
`protection-before.json` قبل الفتح، والقيمةُ النهائيّةُ مقيسةٌ بعده.

**وأُضيف مسارٌ مُعلَنٌ ومُتحقَّق — لا التفافٌ على الحارس:** بعد إعادة الكتابة لا يوجد «مدى دفع» أصلاً،
وكان الحارسُ يسقط بحقّ (`مدىً غيرُ محلولٍ ليس مدىً نظيفاً`). فصار:
`AMOUNT_GUARD_HISTORY_REWRITE=<الأصل> AMOUNT_GUARD_MIRROR=<نسخة احتياطيّة>` ⇒ **يفحص التاريخَ كلَّه**
بدل المدى، **ويُسقط إن لم يُثبت الأصلَ في النسخة الاحتياطيّة**. ثلاثةُ اختباراتٍ تحرسه، منها:

- **فشلٌ مفتوحٌ أُمسك وأُغلق:** تدفّقُ `cat-file` غيرُ المتوقَّع (كائنٌ `commit`/`tree`، أو جسمٌ مقصوص)
  كان **يمرّ صامتاً** ⇒ صار `UnresolvedRange`. **الحكم: قياسٌ ناقصٌ ليس قياساً.**
- **وفشلٌ مفتوحٌ ثانٍ:** المسحُ كان يمشي على جذر الأداة (`ROOT`) لا على **المستودع المقصود** ⇒
  لكان «فتحُ التاريخ في مستودعٍ آخر» يمرّ كأنّه فحصُ هذا ⇒ صار `_git_here` (مستودعُ التنفيذ).

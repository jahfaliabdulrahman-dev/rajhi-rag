## القياسُ الذي بنيتُ عليه (لا رواية)

> **تنبيهٌ مؤرَّخ (مقعدا المعايير والمواصفة · الجولة ٦٨ب):** الرقمُ «٣٦٢٢ كائنًا» مُنقولٌ عن نصّ المدقّق
> ولم أُعِد إنتاجه: قِيس **٣٢٨١** في نسخةٍ معزولةٍ على شجرة هذه الجولة و**٣٢٢٦** في مهمّة الـCI — والعددُ
> يتحرّك مع الشجرة ⇒ فالثابتُ هو **الانتقال من آلافٍ إلى صفر**، لا الرقمُ بعينه (§٢٣: الرقمُ بلا بيئته دعوى).

```
$ python3 tools/publish_guard.py --history --ci
[publish-guard] tree: 461 · history: 0 · messages: 476 — 0 BLOCK / 14 WARN   (rc=0)
```
**وصيغةُ git المقيسة في نسخةٍ صغيرة (خصمٌ على السجلّات):**
```
rev-list --objects --all -z  ⇒  <sha>\0<sha>\0<sha>\0path=<المسار>\0        ← سجلّاتٌ لا أسطر
rev-list --objects --all     ⇒  <sha>\n<sha> \n<sha> <المسار>\n            ← والمسارُ غيرُ مقوَّس هنا
ls-tree -r HEAD -z           ⇒  <mode> <type> <sha>\t<المسار>\0            ← لقاريء الـ`\t` (سليم)
```
**القصُّ إلى الجذر:** عمّمتُ `-z` على كلّ مسارات git وأنا أحسب أنّها «الأسطرُ نفسُها بفاصلٍ آخر».
في `ls-tree` هي كذلك (‎`\t` باقٍ) ⇒ الشجرةُ سليمة (461 ✓). أمّا `rev-list --objects` فبـ`-z` **تتغيّر
بنيةُ السجلّ** (معرّفاتٌ وبوادئُ `path=` **سجلّاتٍ منفصلة** بلا فراغات) ⇒ `line.split(" ", 1)` لا تُطابق
شيئًا ⇒ **تُتخطّى ٣٦٢٢ كائنًا بصمت** فيُخرج الحارسُ «نظيف» وهو لم يقرأ شيئًا.
